## Research routing

Route by where the answer lives. External libraries, upstream harness behavior (Claude Code / Codex / Antigravity), third-party errors and API contracts: web search/fetch and `gh search issues`/`gh api` first; official docs, issues and changelogs are first-class research. This repo's own code and wiring: local search first. Verify any local assumption about external behavior against official docs. New behaviour (design, ui, capability, dependency items) needs a research record before an implementer is dispatched; see `wipnote research --help`.
