Description

Architecture goal (user-requested 2026-06-10): orchestrate Codex CLI and Gemini CLI as headless subagents from a Claude Code session while wipnote captures their sessions — removing the need to run them as independent interactive harnesses. Empirical probe results: Gemini headless (gemini -p) WORKS today — extension hooks fire, session captured (10s probe registered). Codex exec does NOT capture — hooks.json is installed at user level (Claude-Code-style schema, wipnote hook commands) but no session registered even with --dangerously-bypass-hook-trust; root cause unknown (schema mismatch vs exec-mode hook suppression vs handler gap). Codex docs: exec emits JSONL event stream (--json), supports exec resume, and codex mcp-server exposes codex/codex-reply tools — strongest fallback is transcript/JSONL ingest. Gemini has no MCP server mode; headless hooks now empirically confirmed.
