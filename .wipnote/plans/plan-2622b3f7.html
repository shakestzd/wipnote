DesignPending

Problem

wipnote ships 11 skills (about 79 KB) and four slash commands. In 266 Claude Code transcripts for this project (1 to 18 November 2026) nobody typed a wipnote skill by hand except /wipnote:execute, twice. Agents ran the CLI 83 times for delegate and 34 times for plan authoring, and read the matching skills in two and three transcripts. Coder subagents get agent-context preloaded (117 spawns), and delegate workers (60 spawns) get no rules at all. So the guidance costs tokens where it loads and does not reach the agent where the work happens.

Goals

  1. Each rule an agent needs is printed by the command it already runs, or injected once by a hook when a worker starts.
  2. The plugin ships no skill or slash command that the usage count showed nobody loads.
  3. A test fails when a skill file or the system prompt passes a byte limit, so the cut holds.
  4. Each prompt cut is checked with fixed tasks run against the old and the new text.

Constraints

  • The owner alone edits CLAUDE.md, AGENTS.md and GEMINI.md. Slice 11 hands over a proposed text and does not write those files.
  • Generated trees under port/packages and plugin/hooks/hooks.json change only through wipnote plugin build-ports.
  • A skill is deleted only in the same slice that puts its useful lines into command output or help.
  • New guidance text names the work item where the failure was seen (card A1), or it is not added.
  • Codex and Antigravity get the same rules. A rule that only a Claude Code hook can deliver also appears in the command output.
  • Card E4 (retro skill) is out of scope until this plan is done.
  • feat-4151d2f0 (prose check) merges before slice 11 deletes the Simplified Technical English skill.
  • Each slice that deletes a skill also removes its eval cases, its catalog row and every reference to it, except in CLAUDE.md, which slice 12 handles.

What

Write three to five fixed tasks and a script that runs each with wipnote delegate run against the old and the new guidance text, then prints what the agent did side by side. Card A4.

  • A planted regression (the test-first rule removed from the guidance) is flagged by the check

Pass rule: a behaviour that holds in three of three runs on the old ref and in fewer than two on the new ref is a regression. Rejected: a judged score from a second model, because it adds cost and a second source of variance.
