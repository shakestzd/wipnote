Description

Plans are open-ended, so a fixed template cannot know what each plan needs. Design: fixed frame (title, slices, approval state, approve/reject buttons from wipnote plan slices) + a generated body in OpenUI Lang that Claude writes during planning, stored per plan section via the CLI, validated with @openuidev/lang-core at save time, rendered in an artifact twin via @openuidev/browser-bundle, live via the artifact db capability, actions back through room_send -> session.receive (artifact-room). Mods publish with $.tool.call Artifact. Terminal pane draws a subset. Must prove: (1) browser-bundle renders in an artifact with no Gateway or network beyond the CDN; (2) a pinned version at least 2 weeks old exists and the license allows it; (3) Claude writes valid Lang from generateSystemPrompt on 2-3 real plans; (4) lang-core can validate in the CLI or mod. Fallback if (1) fails: Claude-written HTML inside a strict template. Start after the 0.82.0 deploy.
