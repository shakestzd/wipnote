Description

When a repo ignores .wipnote/, every artifact commit intent fails git add, retries 5 times with no per-intent error shown, dead-letters, and wipnote check --gate stays red while pointing at commit-queue flush, the one action that cannot work. Add a git check-ignore probe at enqueue (recordCommitIntent in cmd/wipnote/commit_queue.go) and on flush failure (outboxCommitter), classify the intent as misconfigured rather than poison, and print a targeted message naming the ignore rule and the recommended sessions-only pattern. Scaffold and validate that pattern from wipnote init and launcher doctor. GitHub issue #172.
