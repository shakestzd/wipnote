Description

GitHub #199. recordClaimEpisodeOpen runs after col.Start releases the item lock, and claimledger.Open is idempotent so a restart keeps the pre-completion StartedAt; the completion sweep (cutoff = completion UpdatedAt) then closes the restarted claim. Fix: Collection.Start/Complete accept an OnLocked hook run inside mutateNode's lock; the start-side episode open moves there and opens a FRESH episode (StartedAt = node.UpdatedAt) when the item was not already in progress. The post-commit sweep stays post-commit (rollback safety, TestCompleteSweepsForeignClaimsOnlyAfterCompletionSticks) but re-takes the item lock. closeStartedClaimIfItemDone becomes redundant.
