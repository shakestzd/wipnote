Description

The zero-commit fallback in canonicalCodeBearingPaths (cmd/wipnote/workitem_provenance_canonical.go) runs git status against the shared project root derived from the .wipnote location rather than the worktree the completing agent is in, so under concurrent worktree dispatch a docs-only feature inherits a sibling's dirty files and is falsely blocked. Resolve the git working tree from the caller's CWD or the session's persisted exec worktree path and, when a branch is known, restrict candidate paths to that branch's diff against its merge base. GitHub issue #161.
