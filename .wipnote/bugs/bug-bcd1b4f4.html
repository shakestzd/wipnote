Description

Six Codex P2 findings on PR #223 (merged), all in mods/wipnote-orchestra: 1. register.tsx tool.call: items update before next(e) runs Bash, and applyWipnote matches the whole raw command, so echo/heredoc/comment text or a failed 'wipnote feature start' adds an active item. Apply after the call succeeds, on executable segments only. 2. model.ts showArgv: KINDS lacks trk -> track, so a started track or an agent's track id never loads its title or progress. 3. model.ts parseGitStatus: the branch capture excludes dots, so release/1.2.0 shows as release/1. Parse the ...<upstream> suffix instead. 4. register.tsx: a subagent's lastTool is never cleared when its call returns, so waiting/idle rows keep showing a finished call. Clear it after next(e) settles; keep the count. 5. band.tsx: wrapped segment lines are not capped by room.maxRows, so a narrow pane can draw a band taller than its row budget. 6. register.tsx clock.every: refreshCards can overlap (unawaited, 5 s timeouts), piling up processes and letting an older refresh overwrite newer cards. Guard with one in-flight refresh.
