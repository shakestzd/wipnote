Description

After bug-12ef8d02 the band no longer depends on classic.* events, but the mod still registers classic.UserPromptSubmit, PostToolUse, Stop, Notification and SessionStart. A managed plugin (cc-plugin-sec-default) passes those events past user-tier plugins, and a hot-reloading session prints a transcript line for every skip ('wipnote-orchestra: its classic.Stop hook was skipped...'). Fix: read the permission-mode pill from the SessionMode render component (its props carry the footer's mode labels) and drop every classic.* hook; the conversation swap is already caught by the session-id tracker.
