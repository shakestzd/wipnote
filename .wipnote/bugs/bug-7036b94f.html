Description

Since feat-fc3cc9e0 the PreToolUse hook opens an empty in-memory projection (OpenHookDBReadOnly in core/hooks/dbgate.go), so getClaimFromParentChain and ctx.ClaimedItem from core/hooks/tooluse_shared.go are always empty. checkYoloWorkItemGuard was repaired via canonicalOpenClaim (bug-369da005) but checkSubagentWorkItemGuard and checkYoloSubagentGrace in core/hooks/pretooluse.go still depend on the dead DB path, so a worktree subagent Write or Edit in YOLO mode is blocked with no claimed work item regardless of the orchestrator's claim, re-creating the GitHub #87 symptom through a different dead read.
