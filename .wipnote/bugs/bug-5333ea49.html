Description

Reproduced 2026-10-26 on main (hook called directly): SessionStart with CLAUDE_CODE_ENTRYPOINT set and WIPNOTE_PARENT_SESSION set (WIPNOTE_NESTING_DEPTH unset) writes no sessions-ledger row, because isSubagent() in core/hooks/session_start_env.go treats any parent var with depth != 0 as a subagent. Without the var the row is written with harness claude. In an interactive wipnote claude run the session later gets a row with harness human (a later writer fills the missing row from a fallback identity), so harness-filtered readers miss it. Seen in Phase B (feat-0c976595) runs 1-4: B3a and B2 never found a claude row for Claude workers started inside herdr panes, while B1 (claude -p from the caller's shell) and Codex panes did. Suspected trigger: herdr panes inherit the herdr server environment, which may carry WIPNOTE_PARENT_SESSION from the session that started herdr; to be confirmed by Phase B run 5 (the script now logs inherited variables). Affects delegate: every spawned worker runs in a herdr pane.
