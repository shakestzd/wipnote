Description

core/hooks/missing_events.go TaskCreated mirrors every Claude TaskCreate as a step on the session's active work item (cachedGetActiveFeatureID), so orchestrator process tasks like Draft the plan YAML land on whatever bug or feature was last started and its step counter never advances. Step attachment should require an explicit target (a work-item ID in the task subject or description) or be skipped when the task cannot be attributed, while still recording the agent_event.
