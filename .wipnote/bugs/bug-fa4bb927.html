Description

When a launch's 1s health probe of the live shared collector fails, EnsureShared spawns a replacement on a new port and the old collector steps aside, so running sessions lose their export endpoint. The launcher watchdog then writes 'shared collector moved to port N' to stderr on every move, which garbles the Claude Code prompt, and after the first move it reports the wrong export port. Why Running sessions silently lose telemetry and the warning text corrupts the user's prompt input. Acceptance Criteria A collector that is alive but slow is not replaced on a new port; a replacement reuses the port sessions export to; the launcher never writes collector warnings to the terminal while the child harness runs; the moved warning names the port the session actually exports to and fires once.
