commit-queue: record last_error/failed_at on every failed attempt and show in status

Implementation Steps

  1. ⏳ Add LastError and FailedAt fields to Intent in internal/commitqueue/intent.go and set them in flushLocked on every failure
  2. ⏳ Print one line per failed intent from commit-queue flush
  3. ⏳ Add --verbose to commit-queue status listing pending intents with attempts and last error
  4. ⏳ Extend the commitqueue tests to assert LastError/FailedAt on a retained intent

Description

The #155 fix records Reason and DeadLetteredAt only at the moment an intent dead-letters (internal/commitqueue/flush.go flushLocked). Intents that have failed 1-4 times still carry no failure text, so commit-queue status cannot explain a stuck-but-not-yet-dead queue. Persist LastError and FailedAt on each failed attempt, print per-intent failures from flush, and add --verbose to status to list pending intents with their last error. GitHub issue #174.
