Description

Codex P2 on PR #222 (comment 4309353512, cmd/wipnote/claude_transcripts.go latestClaudeTranscriptSession). The 20-candidate budget is applied to every prefix-matched folder before the recorded cwd is checked. If a sibling such as /repo/app-copy has 20 or more transcripts newer than /repo/app, all 20 are rejected and an older valid /repo/app transcript is never read, so Continue last session disappears. Fix: apply the budget only after the cwd check, for example with a cheap cwd probe (first lines only) before the full label read. Test with 21 newer sibling transcripts.
