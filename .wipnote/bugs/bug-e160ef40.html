Description

GitHub #183 (partial). The reverse proxy uses DefaultTransport (no ResponseHeaderTimeout), the parent http.Server has no ReadHeaderTimeout, and childproc only detects child death. A child that hangs after the handshake keeps receiving traffic (LastRequest bumps keep the idle reaper away) until the user kills it. Scoped fix: proxy header timeout (SSE exempt), parent ReadHeaderTimeout, and a health probe that evicts and kills a child after consecutive misses. Deferred: shared/capped otel-collect, doctor --restart-all, the O(N*H) git cost in hydrate.
