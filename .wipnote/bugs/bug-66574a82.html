Description

Live test 2026-10-29 (run dlg-80e7c5232149): a delegate spawn worker answered its task but could not write .wipnote/delegate/mail/<name>/outbox/<task>-result.json. The Bash write was blocked by core/hooks guardWipnoteWrite (isBashwipnoteWrite), and the Write tool also failed, so the turn ended with no result (watch/wait: idle_shell). runstore/results.go says the worker writes this file itself, as the preamble tells it, but no CLI verb exists for a worker to deliver a result. Fix options: a worker-side CLI verb (e.g. wipnote delegate reply) that writes via runstore.WriteResult, with the preamble updated; or a guard exemption limited to the worker's own outbox when WIPNOTE_DELEGATE_RUN names its run. Also: containsWipnoteDir in core/hooks/pretooluse_shell.go compares an 11-byte slice with the 9-byte '.wipnote/', so the Write-tool guard only matches the bare path '.wipnote'.
