Description

GitHub #306: on macOS Docker Desktop the 'hook inside' check fails; writer.sock is unusable through the bind mount (ENOTSUP) and the container runs wipnote 0.71.0 while the host runs 0.85.0. core/hooks/delegate_bind.go RecordDelegateEvent writes events-<sid>.ndjson as a plain file (containerwrite.AppendLine, no socket); that path shipped in v0.85.0 (77574bea6). Hypothesis: the version gap, not the socket, loses the events. Fix: prove with a test that a container-worker hook records its event with an unusable writer.sock and never blocks on it; make the doctor's 'wipnote inside' check fail when the container's wipnote is older than the host's (or older than the first version with container event files), naming the update command; make sure no hook path waits on writer.sock inside a container worker.
