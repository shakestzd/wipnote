Subagent detection misreads inherited parent and global traceparent queue

Todo Medium Priority

Part Of:

  • trk-2e707ed1

Description

Two gaps found while fixing bug-5333ea49. (1) A bare claude run outside the wipnote launcher, with an inherited WIPNOTE_PARENT_SESSION and no WIPNOTE_NESTING_DEPTH, is still treated as a subagent and gets no ledger row. (2) A session that starts within 30s of any SubagentStart can claim that subagent's traceparent, because the queue in the temp dir is global and not scoped to the parent. That can mark a root session as a subagent and record the wrong parent.
