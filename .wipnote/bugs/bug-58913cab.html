Description

validAutoCompactTokens multiplies the parsed count by 1000 or 1000000 without an overflow check. A value such as 2305843009213694052k wraps into the 100k-1M range, so wipnote forwards the original string and Claude Code rejects it, failing the launch instead of warning and falling back to 300k. Found by the post-merge review of PR #357 (spk-2c9b7e7d).
