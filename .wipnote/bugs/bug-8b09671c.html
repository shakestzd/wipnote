Description

Codex P1 on PR 284. An end note from run 1 caught up after a resume predates the resumed run's start. Store.Close clamped it to that start and closed the live run, so procsweep reported its live processes as orphans. Fix: on a resumed run, ignore an end before the latest run's start.
