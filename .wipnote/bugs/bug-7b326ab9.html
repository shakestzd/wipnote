Description

core/hooks/pretooluse_shell.go containsWipnoteDir compares path[i:i+11] with the 9-character string '.wipnote/'. The two can never be equal, so the function only returns true for the exact path '.wipnote'. Write and Edit calls into .wipnote/ files are not blocked by this guard. The Bash variant works. The length 11 is a leftover from the old '.htmlgraph/' name. Found during bloat slice 9 (feat-ffde27db); left unfixed there because a fix changes behaviour. Fix: compare against len('.wipnote/') and add a two-sided test (a .wipnote/ file path is blocked; a path like 'x.wipnotes/a' is not).
