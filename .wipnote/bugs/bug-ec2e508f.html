Description

Merging origin/main into local main conflicted in .wipnote/gate-ledger.html (both sides only add tr rows). The PreToolUse .wipnote guard blocked git add, sed, git checkout --ours and merge-file writes, so agents could not resolve it; the user had to run the union merge by hand. Needs a ledger merge driver (gitattributes merge=union or a wipnote merge-driver) or a wipnote resolve command.
