From a worktree cwd, findWipnoteDir resolves the main checkout via git-common-dir, so c.Dir = main. canonicalProjectRoot(main) is empty, so launchClaude passed no override and buildClaudeLaunchEnv fell back to effectiveProjectDir -> os.Getwd() = the worktree.
