Description

A managed (prepend-tier) plugin can continue classic.* events past every user-tier plugin. wipnote-orchestra's classic.UserPromptSubmit/PostToolUse/Stop/Notification hooks (permission-mode pill alignment) and classic.SessionStart (rehydrate after /resume, /branch, /clear) then never run. Seen as: 'wipnote-orchestra: its classic.SessionStart hook was skipped. <managed plugin> runs first and sent the event on past it.' Fix: refresh on session.end (reason clear/resume) and the next session.start/turn.complete; draw the band without the pill shift when no mode is known. wipnote's own settings hooks run at core tier and are unaffected.
