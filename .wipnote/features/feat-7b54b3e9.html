# Spec: Mods: questions pane, band count, toast and ref cards

## Problem
The owner sees every open decision in one place and can answer without searching the chat (goal 5).

## Decisions
**Trigger:** pane open (poll while placed), band refresh, card render.
**State:** none in the mod; all data from `wipnote question list --format json`.
**Orchestra:** polling lives in mods/wipnote-orchestra/hooks/register.tsx, so the count and toast detection go there; band.tsx only draws. Ref cards call `question list --item <id> --open --format json` beside the existing show call in refcards.tsx.
**Loading:** the launcher finds mods by reading the mods/ folder and mirrors the tree on deploy; no registration is needed.
**Payload:** the slice 1 JSON row shape.
**Rejected:** a file watch on the store (the existing mods poll the CLI and the store may be outside the repo); putting the list in the band itself (too little room).
