# Spec: File worker questions as records

## Problem
Worker questions are the largest source in the issue's session; they must land on the item instead of in report prose (goal 1).

## Decisions
**Trigger:** `wipnote delegate result NAME` (session.Result in internal/delegate/session/mail.go).
**Source:** session.Questions returns only pending asks and nothing for a closed run (questions.go runQuestions), so this slice adds a reader over all of the run's ask events and question files, excluding KindPermission. The item comes from the ledger row's WorkItem (core/delegationledger/record.go).
**State:** each filed record sets source_id to the worker question id (tool use id or <task-id>-q<n>); a re-run skips ids already present.
**Payload:** worker options are bare strings; each becomes an option with key = its index and no trade-off text. recommended comes from the new `delegate reply --ask --recommended`, otherwise empty.
**Note:** AskUserQuestion is not available in Claude subagents (agent-sdk user-input docs); hook-captured asks only come from workers that run as full sessions, so the outbox file is the primary path.
**Rejected:** parsing an "Owner questions" section from the report prose (owner chose structured only; depends on a heading format workers drift from).
