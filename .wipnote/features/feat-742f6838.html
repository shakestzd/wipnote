Description

Add 'wipnote worktree list' (each worktree: path, branch, dirty, merged state, linked work item) and 'wipnote worktree clean' (removes a worktree and its local branch only when it has no uncommitted or untracked changes and its branch is merged upstream: commits reachable from the default branch, or its GitHub pull request is merged, which covers squash merges). Never touches the main checkout, the current worktree, locked worktrees, or remote branches. Dry run by default; --yes removes. Builds on core/worktree/cleanup.go (InspectCleanupState, RemoveManagedWorktree). Worktrees stay in .claude/worktrees. Why In shared repos where the wipnote store cannot be committed, merged worktrees and branches pile up and must be cleaned by hand; squash-merged branches never look merged to git. Acceptance Criteria 'wipnote worktree list' shows every worktree with merged state; 'wipnote worktree clean' dry-runs by default and with --yes removes only clean, upstream-merged worktrees (including squash-merged PRs) and their local branches; tests cover dirty, unmerged, squash-merged, locked and current-worktree cases.
