Add (1) a short resume brief built from the active work item (id, why, done-when, steps and state, open questions, files touched, linked commits, next step), (2) a PreCompact hook handler for Claude and Codex that snapshots the brief to the session folder and prints summary instructions naming the active item, (3) SessionStart with source=compact injecting the brief in place of the generic startup guidance, (4) a PostCompact handler storing compact_summary on the session record. Why After compaction an agent keeps only the one-line ACTIVE item hint; steps, questions and next action depend on the harness summary, and hook-added context is summarised away. Acceptance Criteria With an active item, a PreCompact payload yields summary instructions naming the item and writes a snapshot; a SessionStart payload with source=compact returns the brief under 8000 chars; no active item yields today's behaviour; manifest registers the events and build-ports output is regenerated; go build, vet and tests pass.
