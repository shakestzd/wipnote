Description

New Claude Code mod modeled on mods/wipnote-orchestra (refcards.tsx, refs.ts). A one-paragraph prompt.compose rule tells the model to emit fenced blocks wip:steps, wip:compare, wip:callout, then wip:check, wip:bars, wip:tree. The model sends only inputs; the mod parses each fence and draws it through ui.render on AssistantMessage. Each parser is a pure function with tests, on terminal and desktop surfaces. Blocks must degrade to readable plain text without the mod. Inputs: steps = one step per line with optional done/next; compare = options with + pros, - cons, * recommended; callout = decision|warning: text; check = item: ok|no|warn; bars = label: value/max; tree = indented lines. Open question to settle by testing: which block syntax the model emits reliably. Keep the rule under 100 tokens. Add a /visuals on|off command.
