Description

TokenEconomizer (microsoft/TokenEconomizer, a Claude Code plugin) cuts token cost by auto-denying tools a repo rarely uses via .claude/settings.local.json. wipnote's workflow relies on rarely-used tools (AskUserQuestion, Agent, Task*, Skill, ToolSearch, wipnote MCP tools). The wipnote claude launcher exports TE_TOOLPRUNE_PROTECT (only when unset) so pruning never removes them. Why Let users run TokenEconomizer alongside wipnote for lower token cost without it silently disabling wipnote's question tool, task mirroring or delegation Acceptance Criteria wipnote claude launch env carries TE_TOOLPRUNE_PROTECT with wipnote's workflow tools, user-set value wins, tests pass
