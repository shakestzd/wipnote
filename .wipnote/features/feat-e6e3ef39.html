Description

Find every live process an agent started, including 'cmd &', nohup, dev servers and watchers that hooks cannot see, by the session id each child inherits. Processes whose session has ended are orphans. status --all and wipnote reconcile list them, with a stop command to copy. wipnote never stops anything.
