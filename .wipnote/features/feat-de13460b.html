Description

Port the regex-checkable lulawrite rules to TypeScript in the mod (pure module, no model calls): BannedVocab, Filler, em dash over 1 per paragraph, SameOpener (3 in a row), NegativeClose without its paragraph-break requirement, Punctuation (curly quotes, en dash between words), plus STE sentence length (20/25) and noun clusters. Skip code fences and inline code. Skip ColonReveal: it is tuned for 950-word documents. Source: shakestzd/luladoc styles/Zinsser/*.yml. Hook session.append on assistant replies. Show the result with the status line, e.g. tells 0, long 1, em-dash 2. Feedback loop: only when a check fails, add one line (about 20 tokens) to the next prompt.compose, naming the word or rule; a clean reply adds nothing. Add /plainspeak strict|80|off. Measure false positives on short chat replies before turning the feedback line on by default.
