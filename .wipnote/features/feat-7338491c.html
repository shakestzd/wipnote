Description

Today delegate wait blocks and returns one outcome, so a caller learns of a worker's question only when wait returns asks. Add wipnote delegate watch NAME [--timeout D]: reuse wait's settle logic, print one flushed line per state change (started, working, asks with the question summary, blocked, done, idle_no_result, gone, stopped, timeout), and exit on any terminal outcome with wait's exit codes. Never prints prompt or answer text beyond the existing bounded summaries. The delegate skill tells Claude Code callers to run it under the Monitor tool and to answer asks with delegate send while it keeps running.
