Description

delegate spawn gives no way to set harness flags, so every spawned worker takes the default model. Add --model and --effort, and pass other harness flags after --. Record the model on the run. Why Delegating small work to cheaper models needs the caller to choose the model, and lineage should show which model did the work. Acceptance Criteria A spawned Claude worker's transcript shows the requested model; a worker given --mcp-config calls that server and a strict config excludes others; flags that break the worker lifecycle are refused; go test passes.
