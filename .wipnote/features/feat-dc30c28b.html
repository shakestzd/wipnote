Description

'wipnote ci watch': a foreground loop, no daemon. Checks poll every 15s while pending; review, base and release every 60s; back off when nothing runs; stop when settled or at --timeout. --json-lines emits a snapshot on change. Exit codes mark passed, failed, timeout and not-available.
