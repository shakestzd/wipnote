Description

From GitHub issue #214 (ask 1). Delegations to external agent CLIs (codex exec|e|review, container claude -p) leave only hook events today. Add a first-class delegation-run record: tool, prompt label, run directory, token usage, exit status, start/end time, linked to the active work item, so the dashboard and recap show each delegation and its lineage. Builds on feat-9b98cd0b (launcher exec passthrough with JSONL capture). Prototype: the herdr-pane mod in #214 writes raw.log, clean.log, clean.md, last.md, usage, exit, start, end, label per run.
