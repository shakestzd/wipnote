Description

wipnote orchestrator enable --strict writes .wipnote/orchestrator.json (mode, violations, max_violations) but no hook reads it: the PreToolUse hook (core/hooks/pretooluse.go) never sees the Skill tool and only debug-logs orchestrator write violations, so strict mode is a no-op for Skill, Bash, Read and Edit from the root session. Load the config in the PreToolUse tool-use context and, for non-subagent sessions in strict mode, warn via additionalContext on non-whitelisted tools (Task, AskUserQuestion, TodoWrite, TaskCreate/Update and Bash wipnote invocations are whitelisted), count violations in orchestrator.json, and block with a delegate-via-Task message once max_violations is reached. Keep the bug-c8ac6a11 rescue path whitelisted. GitHub issues #19 and #20.
