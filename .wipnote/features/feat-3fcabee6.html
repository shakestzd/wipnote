Description

wipnote claude (and yolo, dev, delegate spawn workers that go through the same launch path) passes --autocompact 300k to Claude Code by default. A config key sets another value or turns it off. The launcher adds nothing when the user already passed --autocompact, or when CLAUDE_CODE_AUTO_COMPACT_WINDOW or DISABLE_AUTO_COMPACT is set. Codex is unchanged. Research: spk-b5de17ec. Why Claude Code compacts 1M-context models at about 967K by default; local data shows 75 percent of input-side tokens were sent above 300K and compaction lands near 100K, so 300K cuts cost per turn while leaving about 200K of working room. Acceptance Criteria Launch argv contains --autocompact 300k by default; the config key changes or disables it; a user-supplied --autocompact or the two env vars suppress it; tests cover each case; build, vet and tests pass.
