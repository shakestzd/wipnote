The wipnote claude start-up picker lists every non-done work item touched in this project, with no age limit and no cap, and its session rows carry no prompt text, so users skip it and use /resume. Replace it with a short menu: Start something new; Continue last session (newest Claude transcript for this project, titled by its first prompt, resumed with --resume <id>); up to 3 in-progress work items active in the last 7 days; Browse all sessions (claude --resume with the plugin, Claude's native picker).
