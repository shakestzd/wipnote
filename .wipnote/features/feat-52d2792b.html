Description

BootArgv passes --name info.Name to Claude workers. Instead pass a breadcrumb: the caller session's label, then ' › ', then the worker name. The caller label comes from the caller's Claude session name (its last agent-name transcript entry; info.Caller holds its session id), shortened to its work item id when the name starts with one, else cut to a bounded length; with no readable name, the caller's short session id. A nested worker's parent name already holds a breadcrumb, so the chain grows naturally. The mailbox name, herdr agent name and worker NAME are unchanged; only the Claude session name changes. Why Worker sessions are named only by the worker (fix-ttl, pr-place-1), so Claude Code's /resume lists them as independent sessions and a person cannot tell which parent session spawned them or find the parent to resume. Acceptance Criteria A spawned Claude worker's session shows in /resume as ' › '; nested workers show the full chain; a resumed worker keeps its name; tests cover the label rules and BootArgv.
