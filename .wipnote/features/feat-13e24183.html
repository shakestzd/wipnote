# Spec: Non-blocking by default, blocking questions in execute-preview

## Problem
Work keeps moving without hiding the default it chose (goal 2), and a changed answer is visible and acted on (goal 3).

## Decisions
**Trigger:** item start (`wiStartCmd` in cmd/wipnote/workitem.go calls runWiSetStatus; the hook goes in afterStart in workitem_set_status.go) or an explicit `question assume`; later, `question answer`.
**State:** status open -> assumed on start, assumed -> confirmed or overturned on answer. Questions without a recommended option stay open on start.
**Reopen:** only feature reopen exists today (feature_reopen.go); workitem_reopen.go adds the bug and spike verbs on the same code path.
**Payload:** execute-preview gains a `questions` list of blocking records per item.
**Rejected:** blocking every open question (defeats the non-blocking default the owner chose); silently keeping the assumption on a different answer (the owner chose flag-and-reopen); a follow-up item for rework (owner chose reopen).
