Description

Add --container to delegate run and spawn. The worker runs inside the project's own devcontainer (.devcontainer/devcontainer.json) through devcontainer up and devcontainer exec, never an ad-hoc image. The workspace bind mount carries .wipnote/delegate/, and wipnote's hooks run inside.
